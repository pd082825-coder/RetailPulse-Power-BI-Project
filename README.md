# RetailPulse – Power BI Project

## Retail Sales, Revenue & Returns Performance Analytics

RetailPulse is an interactive Power BI dashboard designed to analyze retail sales performance, revenue, profitability, returns, products, and customers.

## Project Objective

The objective of this project is to transform retail sales data into meaningful business insights using Power BI and help understand sales performance, profitability, customer behavior, and return patterns.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Dashboard Pages

### 1. Sales Overview
- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Sales trends
- Location-wise sales performance

### 2. Revenue & Profit
- Revenue analysis
- Profit analysis
- Profit Margin
- Category and product performance
- Top-performing products

### 3. Return Analysis
- Returned Orders
- Return Rate
- Return trends
- Category-wise return performance

### 4. Product & Customer Analysis
- Product performance
- Customer analysis
- Category and subcategory analysis
- Sales performance by customer segments

## Key KPIs

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Returned Orders
- Return Rate
- Profit Margin

## Key Insights

The dashboard helps identify sales trends, profitable products, high-performing categories, customer patterns, and return performance across different locations.
